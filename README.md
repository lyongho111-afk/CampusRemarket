# Campus re:market v13



사장센터·관리자 화면의 운영 흐름과 안정성을 보완한 버전입니다.



먼저 **v13_변경내역_먼저읽기.html**을 더블클릭해서 변경 요약을 읽어 주세요.



ZIP 전체를 풀고 **세사이트_모두실행.cmd**를 실행합니다. 포함된 Java 런타임을 사용합니다.



- 학생: http://localhost:8080/

- 사장·매니저: http://localhost:8081/ — owner1 / manager1

- 관리자: http://localhost:8082/ — admin1

- 시연 비밀번호: campus1234!



주요 개선: 상태 전용 저장, 동시 수정 충돌 방지, 관리자 처리 이력·메모, 사장 안내, 미저장 내용 보호, 정렬·기간 검색·CSV, 매니저 삭제 인증 토큰 수정.



검증: Java 테스트 38개, 공통 화면 코드 검증 20개 성공. 포함된 런타임 실행과 브라우저 데스크톱·모바일 화면을 확인했습니다.
