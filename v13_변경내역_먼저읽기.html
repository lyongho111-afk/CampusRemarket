이번 버전의 핵심

기존 Spring Boot / Java 25 / MyBatis 구조와 녹색 사장센터·남색 관리자 화면을 유지하고 실제 운영 흐름을 보완했습니다. 소스뿐 아니라 실행 JAR도 다시 빌드했습니다. 압축파일 전체를 풀어 기존 실행 방법으로 사용할 수 있습니다.

구분v12에서 불편했던 점v13에서 바뀐 동작
매니저 삭제본문 없는 DELETE 요청에 CSRF 토큰이 빠져 정상 요청도 거절될 수 있음모든 변경 요청에 세션 토큰 전송
영업 상태 변경가게 전체 값을 함께 보내 메뉴·시간까지 예전 값으로 덮어쓸 위험상태 전용 API에서 영업 상태만 변경
동시 수정오래 열린 화면에서 최신 정보를 덮어쓸 수 있음화면에서 읽은 version과 서버 값을 비교해 충돌 시 409 반환, 입력 내용 유지
관리자 처리승인·공개 중지·사장 배정의 처리 기록을 조회할 수 없음관리자·대상 가게·처리 시각·변경 전후·메모를 운영 이력으로 기록
사장 안내공개 중지 이유를 확인하기 어려움가게 정보 화면에 최근 공개 처리 메모와 시각 표시
목록 조회검색·필터·8개 단위 이동 중심정렬, 8/20/50개 표시, 검색 초기화, 결과/전체 건수, 새로고침 후 조건 유지
이력·거래·평가기간을 좁히거나 결과를 저장하기 불편시작·종료일 검색과 검색 결과 CSV 저장
편집 화면이동 시 수정 내용이 사라질 수 있고 오류 안내가 짧게 사라짐미저장 이동 확인, 글자 수 표시, 처리 중 중복 조작 방지, 화면에 남는 오류 안내

사장센터

  • 대시보드에 가게 소개 준비 점검 추가: 승인, 대표 메뉴, 연락/예약 안내, 여유 공간, 학생 혜택을 실제 저장값으로 확인합니다.
  • 대시보드·가게 정보·영업 관리에서 최신 정보를 다시 가져올 수 있습니다.
  • 영업 상태만 바꾸는 PUT /api/owner/shop/status를 추가했습니다. 상태 변경도 기존 가게 변경 이력에 기록합니다. 동일 상태를 다시 저장하면 새 기록을 만들지 않습니다.
  • 가게·운영 정보 저장에 version을 보내 다른 사용자나 다른 탭의 변경을 감지합니다. 충돌 시 입력을 지우지 않고 최신 정보 다시 불러오기 버튼을 제공합니다. 자동 병합은 하지 않습니다.
  • 입력한 글자 수와 필수 항목을 표시합니다. 저장 전 다른 메뉴로 이동하거나 새로고침/창 닫기를 하면 브라우저 확인을 거칩니다.
  • 변경 이력은 최근 200개 항목에 대해 검색·항목 필터·기간·정렬·표시 개수·CSV 저장을 지원합니다.
  • 가게 정보에 최근 관리자 공개 처리 메모와 시각을 표시하고, 공개 중지와 최초 승인 대기를 구분합니다.
  • 사장은 가게 기본 정보와 매니저를 관리하고, 매니저는 자기 가게 영업 정보와 이력을 이용하는 기존 권한을 유지합니다.

관리자 화면

  • 왼쪽 메뉴에 운영 처리 이력을 추가했습니다. 최근 500건의 공개 상태 변경·사장 배정을 최신순으로 가져옵니다.
  • 실제 값이 바뀐 성공한 처리만 기록합니다. 같은 상태/같은 사장 재저장과 검증 실패는 기록하지 않습니다.
  • 가게 변경과 관리자 이력 저장은 같은 트랜잭션입니다. 이력 저장에 실패하면 공개 상태·배정·version도 롤백됩니다.
  • 승인 검토 창에 가게명·사장·업종·영업시간·메뉴 요약을 표시합니다. 공개 중지 시 화면에서 메모 입력을 요구하고 승인 시에는 선택 사항으로 둡니다. 기존 API 연동을 위해 서버의 메모 필드는 선택 사항이며 최대 300자를 검사합니다.
  • 상세·배정 창에서 휴무일·예약·공간·학생 혜택까지 검토할 수 있습니다. 이미 다른 가게가 배정된 사장은 선택 목록에서 제외하고 서버에서도 중복 배정을 검사합니다.
  • 승인·배정 요청도 version을 검사합니다. 사장 정보 변경 직후 오래된 관리자 창에서 처리하면 최신 정보를 확인하도록 안내합니다.
  • 가게 목록, 거래 현황, 매너온도 평가, 운영 이력에서 검색 결과 CSV를 저장할 수 있습니다. 회원 목록에는 개인정보를 한꺼번에 내려받는 기능을 추가하지 않았습니다.
  • 거래 상세에 약속 시간과 등록 시각을 표시하고, 입금 대기 상태의 한국어 표기를 추가했습니다. 온도 범위를 보여 주도록 평가 요약을 정리했습니다.

공통 사용성

  • 요청 대기 제한과 서버 연결 실패 안내, 마지막 응답 시각 표시를 추가했습니다. 마지막 응답 시각은 지속 연결이나 실시간 구독을 뜻하지 않습니다.
  • 저장 중 버튼을 비활성화하고 해당 입력 양식의 조작을 막습니다. 실패하면 다시 입력할 수 있습니다.
  • 오류는 짧은 알림과 입력 양식 안에 함께 표시합니다. 401이면 로그인 화면으로 돌아가고 첫 방문의 정상적인 로그인 필요 상태에는 만료 알림을 띄우지 않습니다.
  • 저장된 창을 닫은 뒤 불필요한 미저장 확인이 뜨지 않도록 숨겨진 양식은 검사에서 제외했습니다.
  • 메뉴 이동 시 현재 메뉴/문서 제목을 갱신하고 본문으로 초점을 이동합니다. 본문 바로가기, 표 정렬 상태, 필터 라벨, 키보드로 접근 가능한 표 영역을 보완했습니다.
  • 작은 화면에서 도구 모음·기간 검색·입력 양식이 줄바꿈되도록 했습니다. 넓은 표는 표 영역 안에서 가로로 이동합니다.
  • CSV에는 UTF-8 BOM, 따옴표/쉼표/줄바꿈 처리를 적용했습니다. 수식으로 해석될 수 있는 값 앞에는 작은따옴표를 붙입니다. 현재 검색 결과 전체를 저장하며 화면에 가져오지 않은 과거 기록까지 조회하지는 않습니다.

남아 있는 범위와 제약

  • 기존 메모리 H2 시연 구성을 유지했습니다. 공통 서버를 종료하면 회원·가게·이력 등 데이터가 초기화됩니다. 실사용의 영구 저장 구성은 이번 범위에 포함하지 않았습니다.
  • 과거 관리자 처리 이력을 복원하거나 가짜 기록을 넣지 않았습니다. v13에서 성공한 변경부터 기록합니다.
  • 가게 이력 조회는 최근 200개 항목, 관리자 이력은 최근 500건입니다. 검색과 CSV도 이 범위 안에서 동작합니다.
  • 목록은 브라우저에서 검색·정렬합니다. 대용량 운영을 위한 서버 검색·페이지 분할, 회원 정지/삭제, 관리자 임의 거래 변경 기능은 추가하지 않았습니다.
  • v13 화면은 모든 가게 변경에 version을 보냅니다. 기존 API 사용자와의 호환을 위해 version이 없는 이전 형식 요청은 허용하므로, 이전 클라이언트에는 동시 수정 방지가 적용되지 않습니다.
  • MySQL 참고 DDL과 마이그레이션 파일을 갱신했으나 MySQL 서버로 직접 실행한 검증은 하지 않았습니다. 자동 테스트는 H2를 사용했습니다.
  • 인터넷 공개 서버에 배포하지 않았습니다. 이전 문서의 공유 주소는 역사 자료이며 v13 배포 주소가 아닙니다.
  • 압축파일 안의 docs/v10~v12 문서는 당시 이력으로 유지했습니다. 현재 사용 기준은 루트 README.md와 v13 문서입니다.
