# 실제 카드 화면 검증

검증일: 2026-10-29. MyBatis 서버를 실행해 브라우저에서 직접 버튼을 눌러 확인했습니다.

- 기본 URL /sales/selectAll에 기존 카드형 디자인 표시, 표 화면 및 기존 시안 선택 메뉴 제거
- 판매글 28,000원 등록 후 내 판매글 8 → 9개 반영
- 할인율 20% 입력 시 22,400원 자동 환산 및 서버 저장
- 할인 중 제목 수정, 끌어올리기 후 재사용 대기 표시
- 할인 가격 22,400원으로 예약 확정, 지도·결제 페이지에 같은 약속 가격 표시
- 거래 장소 학생회관으로 변경·저장
- 대면 거래 완료 상태 반영
- 동네생활 글 등록 후 목록에 즉시 표시
- Google 지도 임베드·지도 링크와 키 설정 경로 확인
- 토스 테스트 키 미설정 상태에서 결제 비활성화 안내 확인

실제 토스 테스트 키를 사용한 결제창·승인 성공은 검증하지 않았습니다. 서버 종료 시 메모리 DB가 초기화됩니다.
