## 최종 실행 JAR 확인
포함된 app/runtime의 Java로 최종 bootJar를 별도 로컬 포트에서 실행해 학생 가입과 실제 학번 로그인, 판매글 등록, 다른 학생의 예약, 거래 완료, HTML 평가 폼, CSRF 평가 API, temp=366 및 판매자 카드=36.6도를 확인했습니다. 공유용 실행 설정의 H2 관리 콘솔 비활성화도 확인했습니다. 검사 후 해당 로컬 검증 서버는 종료했습니다.

## 배포 파일 일치
