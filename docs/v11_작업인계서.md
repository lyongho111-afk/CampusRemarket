# v11 현재 작업 인계

학생 화면 36개는 v10과 동일하고 사장/관리자 사이트를 별도 주소·프로세스·로그인 세션으로 추가했습니다. 공통 API/DB를 공유합니다. 전체 테스트 30개 통과, JAR와 ZIP 갱신 완료.

공개 범위 추가 안내 뒤 사용자가 계속 진행에 동의하여 사장·관리자 Cloudflare 공유를 완료했습니다. 세 주소와 계정은 v11_공유주소.md 참조. 모두 HTTPS 응답과 역할별 로그인 확인 완료. 학생 기존 공유 주소도 v11 공통 서버로 갱신했습니다.

공개 실행은 work/share/v11-processes.json의 PID를 사용하며 공통 서버18082, 사장18084, 관리자18085입니다. H2 콘솔 비활성화와 프록시 헤더 설정을 유지합니다. 원본 ZIP과 IdeaProjects는 수정하지 않았습니다. 새 소스 변경 후 bootJar를 빌드하고 app/campus-remarket.jar 교체가 필요합니다. 메모리 DB는 공통 서버 재시작 시 초기화됩니다.

사장/관리자 상세 기능·추가 파일·회원 코드 변경점·실행법은 README와 docs/v11_변경내역.md를 참조하세요.
