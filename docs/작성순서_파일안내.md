# start07 참고 MyBatis 작성 순서

DTO.java → DAO.java → Mapper.xml(SQL 작성) → Service.java → Controller.java → 화면(.html)

|기능|DTO|DAO|XML|Service|Controller|
|---|---|---|---|---|---|
|판매글|SalesDto|SalesDao|SalesDao.xml|SalesService|ProductApiController / SalesController|
|게시판|BoardDto|BoardDao|BoardDao.xml|BoardService|BoardApiController / BoardController|
|가게|ShopDto|ShopDao|ShopDao.xml|ShopService|ShopApiController / ShopController|
|거래|TradeDto|TradeDao|TradeDao.xml|TradeService / PaymentService|TradeApiController / TradeController / IntegrationApiController|

Java는 src/main/java/com/campus/remarket, SQL Mapper는 src/main/resources/mappers에 있습니다.
메인 HTML은 src/main/resources/templates/market/index.html입니다.
카드 화면 JS는 src/main/resources/static/preview/app.js, 공통 표시 features.js, 지도·결제 integrations-live.js입니다. app.js에서 fetch로 JSON Controller를 호출하고 Controller가 Service를 부릅니다. Service가 DAO를 호출하면 MyBatis가 같은 메서드명의 XML SQL을 실행합니다.

판매글·게시판·거래의 기존 학습용 Thymeleaf 폼은 templates/sales,board,trades에 유지했습니다. 가게는 학생용 조회만 노출하며 편집 폼은 제거했습니다. 메인 판매글 URL /sales/selectAll은 카드 화면이며 표 목록은 /sales/manage로 이동했습니다. 기존 화면 시안이라는 별도 메뉴는 없습니다.

학생 가게 화면: ShopDto → ShopDao → ShopDao.xml → ShopService → ShopApiController → market/index.html (shops.js/shops.css). 지도와 읽기 전용 가게 목록을 나란히 표시합니다. /shops/selectAll은 /sales/selectAll#shops로 이동합니다.
