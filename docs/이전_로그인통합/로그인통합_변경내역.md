# 로그인 통합 변경 내역

기준: 두 번째 ZIP의 `campus-remarket` 프로젝트. 입력 ZIP 두 개는 덮어쓰지 않았습니다.

## 첫 번째(팀원) 파일의 변경

회원 Java 21개 + HTML 3개 + CSS 1개 = **25개 파일 원본 그대로**. `회원원본_SHA256비교.json`에서 파일별 해시를 확인할 수 있습니다.

변경된 파일은 `src/main/resources/static/member.js` 하나입니다.

```diff
 const next = me.role === 'OWNER' ? 'manager.html'
-           : '/api/members/me';
+           : '/';
```

이유: 학생·매니저·관리자 로그인 후 연습용 회원정보 JSON 화면 대신 통합 마켓으로 이동하기 위해 변경했습니다. 사장의 `manager.html` 이동은 유지했습니다. 비밀번호 검사, 회원가입, 이메일 인증, 저장소, 역할 검사는 수정하지 않았습니다. 정확한 원본 문맥은 `팀원파일_변경.diff`에 있습니다.

별도로 추가한 `MemberPageConfig` + `member-navigation.js`가 세 회원 페이지에 마켓 복귀 링크를 표시합니다. 저장된 팀원 HTML은 변경하지 않고 응답 시 스크립트를 연결합니다.

## 첫 번째 프로젝트에서 가져온 것 / 합친 설정
- `src/main/java/demo/campus/campusremarketmember/member/**` 전체를 같은 패키지 경로로 추가했습니다.
- `login.html`, `signup.html`, `manager.html`, `style.css`, `member.js`를 static에 추가했습니다. preview의 동명 style.css는 별도 경로여서 충돌하지 않습니다.
- 첫 번째 `CampusRemarketMemberApplication.java`는 추가하지 않았습니다. 별도 애플리케이션을 두 개 실행하면 같은 8080 포트와 DB 설정이 충돌하므로 기존 `CampusApplication` 하나에서 두 기능을 실행합니다.
- 첫 번째 build.gradle/settings.gradle/application.properties를 덮어쓰지 않았습니다. 두 번째 Boot 4.0.2 / Java 25 / Gradle 9.3.0을 유지하고 JPA와 spring-security-crypto만 추가했습니다. 별도 spring-security 전체 로그인 필터는 추가하지 않았습니다.
- `MemberIntegrationConfig`: 팀원 패키지의 컴포넌트·엔티티·JPA 저장소를 명시적으로 등록합니다.
- 기존 MyBatis의 schema.sql/data.sql, 상품·가게·게시글·거래 테이블을 유지했습니다. JPA는 회원의 member/school/email_verification 테이블을 생성합니다.

## 두 번째(마켓) 프로젝트에서 변경한 부분
- `build.gradle`: JPA/BCrypt 의존성 추가, 통합 실행 클래스 명시.
- `application.properties`: 회원 JPA 생성 설정, 시연 메일 설정, 오류 메시지와 세션 쿠키 설정 추가.
- `MarketMember`: 팀원 LoginSession과 MemberService를 통해 현재 회원을 읽고 `member:회원번호`를 기존 문자열 ID 필드에 연결. 본인 글/거래 참여자/구매자 검사와 거래 목록 필터 제공.
- `MemberIntegrationController`: `/api/session`으로 로그인 상태·안전한 회원 DTO·작성자 키 제공.
- `MemberErrorAdvice`: 회원 API 오류의 HTTP 상태와 안내 메시지를 JSON으로 반환.
- `ProductApiController`, `BoardApiController`: 예시 계정 고정값 제거, 세션 회원으로 저장, 본인 글만 변경 허용.
- `TradeApiController`: 세션 구매자로 예약, 자기 상품 구매 금지, 본인 거래만 목록 표시, 참여자만 변경 허용.
- `IntegrationApiController`: 구매자만 결제 준비/승인 API 요청 허용.
- `SalesController`, `BoardController`, `TradeController`: 기존 HTML 폼 경로에도 동일한 회원/소유권 검사 적용.
- `templates/market/index.html`, `static/preview/index.html`: 회원 메뉴와 세션 스크립트 추가. `templates/common/nav.html`: 회원 화면 링크 추가.
- `session.js/session.css`: 로그인/회원가입·회원 이름·매니저 관리·로그아웃 메뉴, 세션 조회와 작성자 키 제공.
- `preview/app.js`, `features.js`: 내 판매글을 실제 회원별로 필터, 로그인 후 작성 허용, 다른 회원 게시글의 수정·삭제 버튼 숨김, 세션 확인 후 데이터 로드.
- `integrations-live.js`: Toss 테스트 구매자 키를 실제 회원별로 설정, 판매자에게 구매자 결제 버튼 비활성화.
- `member-navigation.js`와 `MemberPageConfig`: 회원 페이지에서 마켓으로 이동하는 링크 추가.
- `MemberIntegrationTests`: 실제 HTTP 및 별도 브라우저 쿠키 저장소를 사용하는 통합 테스트 4개 추가.
- `app/campus-remarket.jar`: 변경한 소스로 새로 빌드한 실행 JAR로 교체. 포함 Java 실행 환경 및 실행하기.cmd는 기존 파일을 유지했습니다.

## 유지한 범위
회원 기능을 MyBatis로 다시 작성하지 않았습니다. 회원은 JPA 원본 그대로, 마켓은 MyBatis 그대로 함께 사용합니다. 기존 예시 글의 작성자를 특정 회원에게 강제 배정하지 않았습니다. 기존 마켓의 화면 구성, SQL Mapper, 서비스의 할인·가격·거래 계산 규칙은 유지했습니다.

학교 메일 인증은 시연 모드이고 DB는 서버 종료 시 초기화됩니다. 기존 사장 매니저 관리는 제공하지만 가게 테이블의 ceoid/man1~3 필드와 회원 테이블을 자동 동기화하는 별도 가게 관리 기능은 추가하지 않았습니다.
