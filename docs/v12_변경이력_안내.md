# v12 — 사장 사이트 변경 이력 조회 추가

사장센터 왼쪽 메뉴의 **변경 이력 조회**에서 우리 가게의 변경자·역할·변경 시각·변경 항목·변경 전후 값을 조회합니다. 검색, 항목 필터, 페이지 이동을 지원하며 최근 200개 변경 항목을 최신순으로 표시합니다.

영업 상태/영업시간/여유 공간/메뉴/휴무일/학생 혜택/전화/예약 안내/가게명/업종/공간 소개 변경을 기록합니다. 한 번 저장할 때 여러 값을 변경하면 항목별로 기록됩니다. 같은 값 재저장, 검증 실패, 저장 실패는 기록하지 않습니다. 가게 변경과 이력 저장은 같은 트랜잭션이며 이력 저장이 실패하면 가게 변경도 롤백됩니다.

사장과 해당 가게의 매니저만 조회할 수 있습니다. 요청에 다른 가게·사장 번호를 넣어도 접근 대상을 바꾸지 않습니다. 변경자 이름과 역할은 로그인한 회원을 서버가 결정하며, 매니저 계정을 삭제해도 이전 기록의 이름은 남습니다.

**기능 추가 이후 저장한 변경부터 기록합니다. 이전 변경은 복원하거나 가짜로 생성하지 않았습니다.** 현재 메모리 H2 구성은 유지하여 공통 서버 종료 시 이력도 다른 데이터와 함께 초기화됩니다.

실행: ZIP 전체를 풀고 `세사이트_모두실행.cmd`. 기존 학생/사장/관리자 주소는 localhost 8080/8081/8082이며, 계정 owner1/admin1, 시연 비밀번호 campus1234!입니다. 사장 사이트의 기존 공유 주소도 유지했습니다. 학생 화면 파일과 관리자 화면은 변경하지 않았습니다. 회원 담당 코드도 이번에는 추가 수정하지 않았습니다.

변경 파일:
- dto/ShopChangeDto.java, portal/ShopChangeDao.java, mappers/ShopChangeDao.xml 추가.
- StaffPortalService: 성공한 자기 가게 정보/운영 수정과 같은 트랜잭션에서 변경 항목 기록.
- StaffPortalController: GET /api/owner/shop/history 추가.
- schema.sql 및 참고 H2/MySQL DDL: shop_change_logs 테이블·조회 인덱스 추가.
- portal-sites/owner/index.html, app.js, styles.css: 메뉴·이력 표·검색·필터·새로고침·빈 목록 안내 추가.
- StaffPortalTests: 실제 변경/동일 값/실패, 매니저 삭제 후 이름 보존, 다른 가게 차단, 이력 저장 실패 시 가게 변경 롤백 검증 추가.

테스트 33개 모두 성공했습니다(기존 30 + 새 3). JS 문법 검사도 통과했습니다. 최신 bootJar를 app/campus-remarket.jar로 교체했습니다. 이후 소스를 수정하면 gradlew.bat test bootJar 후 실행 JAR를 교체하고 사용하는 서버를 재시작해야 합니다. 상세한 기존 사이트 실행 구조는 docs/v11_README.md를 참고하세요.
