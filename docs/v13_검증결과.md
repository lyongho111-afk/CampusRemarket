StaffPortalTests의 기존 9개에 다음 5개를 추가했습니다.

1. 상태 전용 저장이 메뉴/시간을 유지하며 오래된 기본·운영 저장을 409로 거절하고 동일 상태에는 중복 이력을 남기지 않는지 확인.
2. 같은 version으로 두 HTTP 요청을 동시에 보내 정확히 하나만 200, 나머지는 409인지 확인.
3. 관리자 메모·공개 처리·사장 배정 이력과 같은 값/실패 시 무기록, 잘못된 승인 입력, 오래된 version, 300자 제한, 사장 화면 안내를 확인.
4. 익명·사장·매니저의 관리자 이력 접근 차단 및 관리자의 사장 상태 변경 차단 확인.
5. 관리자 이력 INSERT에 강제 DB 오류를 발생시켜 공개 상태와 version이 함께 롤백되는지 확인.

20개 공통 화면 검증은 두 사이트 각각에서 본문 없는 DELETE 토큰, GET 헤더, version 포함 PUT, CSV 따옴표 및 수식 처리, 409 오류 전달, 보이는 미저장 양식 감지와 닫힌 양식 제외를 검증합니다. 실제 브라우저 전체 흐름 검증과는 별개인 함수 단위 검증입니다.

## 실제 브라우저 확인

- 포함된 런타임으로 세 사이트를 시작하고 8080/8081/8082 응답 확인.
- owner1과 admin1 로그인 및 별도 포트의 세션 동작 확인.
- 영업 정보 편집 중 메뉴 이동 취소 후 입력 유지 확인.
- 운영 저장 → 변경 이력의 변경 전후 반영 확인.
- 변경 이력 CSV를 실제 다운로드하고 한국어 헤더/행, 따옴표 구분 내용 확인.
- 같은 사장 계정 두 탭에서 먼저 저장한 최신 데이터와 충돌하는 요청에 오류가 나오며 두 번째 탭 입력이 남는지 확인.
- 관리자 공개 중지 메모 저장 → 운영 이력 반영 → 사장 가게 정보의 관리자 안내 확인.
- 다시 승인·공개 후 두 건의 운영 이력 확인.
- 검색 0건 안내·초기화, 새로고침 후 검색어/결과 유지, 열 정렬과 역전된 날짜 안내 확인.
- 데스크톱과 390×844 모바일 크기에서 화면 확인. 모바일 문서 clientWidth와 scrollWidth가 모두 375px로 일치하고 넓은 표는 내부 스크롤을 사용함을 확인.
