# 학생 화면 수정본 v9

- 배너 아래 중고거래·동네생활 바로가기 바 제거
- 가게 탭: 왼쪽 Google 지도 / 오른쪽 공강에 들르기 좋은 곳 목록
- 작은 화면: 지도 다음에 가게 목록 표시
- 가게 상태 변경 시연과 가게 등록·수정·삭제 화면 제거, 영업 정보 조회만 제공
- 나머지 메뉴와 판매글·할인·끌어올리기·예약 기능 유지
- DTO → DAO → XML(SQL) → Service → Controller → HTML 구조 유지

전체 소스, SQL, 계획서, Windows 64비트 실행 환경을 포함합니다.
ZIP 전체를 압축 해제한 후 실행하기.cmd 실행 → http://localhost:8080/ 접속.
사장·관리자 페이지는 이번 작업 범위에 포함하지 않습니다.
