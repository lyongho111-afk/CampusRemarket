# 로그인·회원가입 정렬 수정

2026-11-01

- 회원 메뉴의 폭 기준을 본문과 동일한 1180px, 좌우 여백 32px로 맞췄습니다.
- 800px 이하에서는 본문과 동일한 20px 여백을 사용합니다.
- CSS 캐시 갱신용 버전 표시를 추가했습니다.
- Gradle bootJar로 실행 JAR를 다시 만들었습니다.
- 실제 실행 화면에서 회원가입 오른쪽 좌표와 본문 오른쪽 좌표가 1190.5px로 같음을 확인했습니다.
- 수정 파일: static/preview/session.css, static/preview/index.html, app/campus-remarket.jar.
- 기존 v13 테스트 기록은 당시 기록이며 이번 CSS 수정에서는 빌드와 브라우저 화면 정렬을 확인했습니다.

전체 압축을 풀고 세사이트_모두실행.cmd를 실행하세요. 기존 서버가 실행 중이면 먼저 종료한 뒤 새 파일로 실행하세요.
